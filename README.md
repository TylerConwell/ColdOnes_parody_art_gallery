# ColdOnes_parody_art_gallery

This is a fun parody website that I designed to parody the youtube channel Cold Ones.

Description
This is a parody website that just shows a few of my favorite posters that i feel encapsulate the humor of the show into a "if you know you know" kind of humor. Nothing to high brow here on this project it has some simple glow to it that i feel makes the posters pop as well as some dumb one liners either from the show or my own spin on things. 

If you like it feel free to add onto it, i make it on react ill add onto this one occasionally as I see funny episodes of the show and want to add it to the site. I'll probably add really badly aged memes and egg fella somewhere here at some point. Just like to show my love for the show and to share some flavor on my repo.

Getting Started
Dependencies
This project requires a modern version of Node.js. It was built using the following versions:

React: ^19.2.0
React-DOM: ^19.2.0
Vite: ^6.0.0
Installing
Clone the repository:
git clone https:github.com/TylerConwell/ColdOnes_parody.git
Navigate to the folder:
cd coldones_react
npm install
Executing Program
To run the program in development mode:

npm run dev
